# 6．独立成分分析：模型、判读与去成分

## 模型先于按钮

独立成分分析（Independent Component Analysis，ICA）常用模型为 `X = A S`：`X` 是多通道记录，`S` 是源时间序列，`A` 描述每个源投射到各通道的权重。算法估计解混矩阵 `W`，使 `S_hat = W X` 的各行在某种统计意义上尽量独立。

这是对记录的模型，不保证每个分量都恰好对应一个解剖脑区或一种纯伪迹。统计独立也比不相关更强；两个变量不相关，不意味着没有其他统计关系。

主成分分析（Principal Component Analysis，PCA）寻找解释方差的正交方向，目标不同于 ICA。PCA 可以用于白化和有效维度处理，但不能把二者合称“独立主成分分析”。

## 为什么有时能分离眨眼

若眨眼在多个电极上的投影模式较稳定，且与其他活动具有足够不同的统计结构，分解有机会把其主要贡献集中到某些成分。但运动、电极变化、少量数据和严重混合可能使分离不完整。

稳定空间混合是重要假设。中途重新戴帽、移动电极或接触状态明显变化，应检查前后投影是否仍可由同一矩阵描述；不能只按文件名把不同记录拼成一次分解。

## 拟合前检查

1. 选择适合共同模型的通道；头皮、双极眼电、外周肌电和触发不能无条件混合处理。
2. 排除持续坏通道和罕见严重坏时间段，保留有助于学习目标伪迹的代表性样本。
3. 确认参考、单位、通道顺序和有效秩；成分数不能高于可用独立维度。
4. 准备足够且有代表性的记录。时间点数的经验公式是经验，不保证分解成功；重复或高度相关的样本不能当成同等的新信息。
5. 记录算法、版本、参数、随机种子、输入通道和所用数据区间。

## 连续还是分段

连续数据通常保留更多样本，也便于避免分段基线操作。分段拟合也可以合理，但重复重叠的时间点会被重复计入统计分布；要知道训练数据中哪些采样点实际出现了多次。

拟合前通常避免对每个短试次分别减基线，这会为各通道各试次引入不同偏移。需要电位基线时，可在清理后按分析目的处理。

## 不靠一个标签决定删除

| 观察 | 能支持的判断 | 不能单独推出的结论 |
|---|---|---|
| 额部强投影、波形与眼电事件对应 | 可能含较强眼动贡献 | 所有额部成分都是眼动 |
| 头皮边缘局灶投影、宽带较高频增强 | 可能含肌电 | 任意高频增强都应删除 |
| 窄工频峰 | 可能有电源干扰 | 该成分不含任何脑活动 |
| 平滑、近偶极子分布及合理节律 | 支持脑源解释 | 已证明是单个特定脑区 |
| 自动分类概率较高 | 提供筛查证据 | 在你的数据集里有相同的已校准正确率 |

综合成分地形图、时间序列、频谱、与辅助通道的关系和单试次分布。自动分类器是辅助证据，应保留概率、人工决定和原因，抽查高低置信度成分。

## 去成分实际做了什么

删除指定分量后，算法用其余分量重建通道数据，相当于某种空间投影。投影是线性的，不等于不会改变波形、频谱或相位；被移除分量若含目标脑活动，就同时移除了这些信息。

“只保留高概率脑成分”和“只删除明确伪迹成分”是不同策略。前者可能丢掉难分类但有用的活动，后者可能残留混合污染。应按目的评价，并报告选择依据，而非视为等价。

## 迁移权重与再次拟合

将训练副本的解应用到分析副本时，必须一致地处理通道集合、顺序、参考、缩放和空间维度。不要在拟合后悄悄加减通道或仅改变通道数据的参考。软件可能提供同步变换，但仍需核对模型定义。

去掉一个成分后再次拟合，不能恢复被删掉的独立信息；但也不能保证其余成分逐个原样返回。若怀疑训练被异常坏段破坏，可回到保留完整维度的上游副本，调整训练样本后重新评估。

## 结果检查

比较去成分前后同一时间段，检查伪迹减少的位置与幅度、剩余眼动、目标响应、频谱和异常补偿成分。只看平均波形可能掩盖少数严重试次，因而还要看单试次。
