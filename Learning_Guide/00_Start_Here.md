# 从零学习：先理解问题，再选择处理

> 本目录是新增的中文教学说明，不是两套网页的逐段译本。与已有英文整理稿的校译分开维护。版本与覆盖情况见[覆盖清单](../docs/COVERAGE.md)。

脑电（Electroencephalography，EEG）预处理，是把采集记录变成适合某个分析问题的数据表示。处理后的数据并不自动等于“真实脑活动”：去噪方法可能残留干扰，也可能删除目标信息。

## 用同一组问题学习每种方法

1. 输入里有什么具体问题，证据是什么？
2. 算法利用了哪种区别：频率、空间分布、统计分布，还是事件时间？
3. 方法依赖的假设在我的数据中是否合理？
4. 参数改变的是哪种权衡？
5. 处理前后应检查哪些量，才能发现失败或过度清理？

例如，看到额部大波不能立刻认定它是眨眼。先检查时间形态、空间分布、眼电记录与事件关系。确认干扰后，再判断分解、回归、删除受影响片段等方案是否合适。

## 三种层次不要混在一起

- **数学事实**：减去同一个常数不能消除一条曲线的斜率。
- **经验建议**：某组滤波设置常使某类数据的独立成分更容易解释。
- **数据结论**：你在当前记录中实际观察到漂移减少、成分更稳定，但某个目标慢波也发生变化。

数学事实可以推导；经验建议需要边界条件；数据结论需要实际检查。教程中的示例值，不会因反复出现而变成统一标准。

## 本轮学习的边界

先聚焦常规头皮记录。同步磁共振、经颅刺激、睡眠、婴幼儿、运动和临床记录可能需要额外处理；出现这些数据再扩展。源定位、功能连接和群组统计可在掌握单被试数据后学习，见[进阶地图](../EEGLAB_Tutorials/Advanced_Topics_Map.md)。

每次练习保留原始数据和一份修改副本，写下预测，再比较结果。仅仅让波形更平滑、删除比例更低或条件差异更显著，都不能单独证明处理正确。
