# 2．事件、通道与原始数据检查

## 目的

在任何清理之前确认“数据是什么”和“事件何时发生”。单位错误、通道对应错误、事件错位会直接改变后续解释，无法靠多跑一次去噪算法补救。

## 第一轮检查

| 项目 | 要确认的内容 | 典型失败 |
|---|---|---|
| 数据尺寸 | 连续数据常为通道×时间点，分段后还包含试次维度 | 把试次或通道维度当成时间 |
| 幅度单位 | 导入后的伏、毫伏、微伏及缩放记录 | 阈值相差一百万倍 |
| 采样率 | 实际值、记录时长与采样点数相符 | 时间轴和频率轴一起出错 |
| 通道类型 | 头皮、眼电、心电、肌电、触发、参考及未连接端口 | 辅助或数字触发进入头皮平均 |
| 通道位置 | 标签、坐标单位、左右方向、实际布局 | 插值和头模配准错误 |
| 记录参考 | 采集参考以及导入时是否做过转换 | 重复加回或误加参考 |
| 硬件处理 | 采集带宽、滤波、增益、饱和和缺失记录 | 想恢复采集时已经丢失的信号 |

模板坐标是对位置的近似；电极名称与模板匹配成功，不等于实际个体位置已经准确测量。

## 事件字段不是普通文字标签

在工具箱事件结构中，`type` 表示事件类型，`latency` 表示事件位置。内部事件延迟通常以采样点表达，界面或导入文件却可能使用秒、毫秒或其他单位；转换时必须看具体接口。

采用以1为起点的采样点索引时，连续记录中的秒数可按 `(latency - 1)/fs` 换算。不要把这一换算直接套给所有外部文件：有些从0开始，有些相对于各自片段或独立时钟。

```matlab
% 教学检查：仅用于已加载的单个连续数据集
assert(EEG.trials == 1, '本示例只说明连续记录的时间换算');
fs = EEG.srate;
eventSamples = [EEG.event.latency];
eventSeconds = (eventSamples - 1) / fs;
```

在样本记录中先人工挑三到五个事件：核对类型、发生位置及与任务日志的关系，再做批量转换。

## 时间误差有几种

- **固定延迟**：触发标记到真实屏幕或声音刺激间隔近似固定。只有经过测量，才有依据做统一补偿。
- **随机抖动**：每次误差不同，会模糊事件锁定的平均波形；减去一个常数不能修好它。
- **时钟漂移**：两台设备随记录时长逐渐错位，需要校准时钟对应关系，而不是只对齐开头。

优先使用光电二极管、音频回录或同步测试等实际测量。不要为了让波形“看起来对齐”而移动事件。

## 删除时间段后会发生什么

删除一段连续数据，新的时间轴不再等同于原始时间轴。工具箱通常会更新事件位置，并加入 `boundary` 边界事件。它提醒后续操作这里并非物理连续，不能把边界两侧当作没有中断的记录。

原始事件记录与当前事件表应一起保留。导出到其他工具时，也需要导出时间映射或删除掩码，否则任务日志可能无法再对应。

## 辅助通道怎样保留

眼电和心电不一定参与同一个分解或参考，但仍能帮助确认伪迹时间、评价自动成分标签及剩余干扰。保存原始辅助记录，按处理需要选择参与通道；“不参与这一步”不等于“永久删除”。
