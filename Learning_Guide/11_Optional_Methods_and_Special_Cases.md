# 11．其他常见方法：先知道用途和代价

> 新增方法地图，不穷尽全部研究算法。先读主要章节，再按实际问题深入；这些不是每份数据都要添加的步骤。

| 方法 | 目的与基本原理 | 条件、效果与主要风险 |
|---|---|---|
| 去均值 | 减去一段信号的平均值 | 消除该段常数偏移；不去除斜率，不等于全部漂移被清除 |
| 线性或分段去趋势 | 拟合并减去低阶趋势 | 可能同时减去真实慢变化；分段拟合及拼接需检查边界 |
| 辅助通道回归 | 用眼电等记录预测各脑电通道的相关贡献并相减 | 系数估计依赖数据与模型；辅助通道也可能含脑活动，存在过度扣除与未建模残留 |
| 信号空间投影 | 估计干扰方向，把数据投影到其正交补空间 | 干扰空间若与目标信号重叠会损失目标信息；投影影响数据秩及后续模型 |
| 回归式基线处理 | 把基线与后续数据的关系纳入统计模型 | 可放松固定均值相减的一些假设，但需要合理模型与窗口，不能自动解决全部基线偏差 |
| 表面拉普拉斯变换 | 根据头皮空间导数强调较局部的空间变化 | 改变表示和单位，依赖电极密度、位置与平滑；不是去除所有容积传导或完成脑内源定位 |
| 局部通道/时间修复 | 只对受影响局部估计或插值 | 比整条通道替换更有针对性，但需要记录修复范围，检查边界与信息依赖 |

## 与主要方法怎样区分

回归使用可观测辅助信号及其预测关系；独立成分分析依靠多通道统计分离；信号空间投影直接排除估计的空间方向。它们可能解决部分相同伪迹，但采用的假设和信号损失不同。不能认为叠加越多种方法就越干净。

信号空间投影（Signal Space Projection，SSP）通常由代表性伪迹数据估计方向；应用后剩余的空间维度需要下游处理正确识别。

表面电流密度（Current Source Density，CSD）在头皮分析中常与表面拉普拉斯估计联系。它不是把电压数值换个参考那么简单，也不能与三维脑内电流密度估计直接等同。

## 特殊采集情形

- 同步磁共振记录包含梯度和脉搏相关等专门伪迹，需要同步与专用方法。
- 经颅刺激可能产生饱和与放大器恢复过程，需要明确哪些数据实际未被可靠记录。
- 自由运动记录中的电极、线缆及肌肉变化可能持续改变空间结构，固定模型需要额外检查。
- 婴幼儿、患者、睡眠或少通道记录的可用时长、信号形态和模型适用性不同，不能直接沿用成人静坐范例。

这些情形应先查相应设备与方法资料，再决定流程；普通模板不能保证覆盖。

## 方法叠加前的三个检查

1. 上一步已经移除了哪些信息？下一步是否还依赖这些信息？
2. 是否对同一种干扰重复估计，从而增加目标信号损失？
3. 是否仍有上游副本和掩码，能判断新步骤实际带来的收益？
