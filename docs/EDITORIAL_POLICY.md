# 文档标注与修订规则

本轮范围依据用户选择：修订仓库已有内容，补齐中文学习讲解；尚无原文全文翻译授权说明，因此不把网上两套教程全文翻译后发布。

## 内容类型

| 标签 | 含义 |
|---|---|
| 既有英文整理稿 | 原仓库已经提供的英文内容，可能包含节选、转述和拼接；不是逐字原文 |
| 校订中文 | 对已有英文笔记进行修订；不确定内容与证据不足处另行说明 |
| 学习注释 | 用于解释数学、假设、参数、限制和检查方式的新增教学内容 |
| 原文入口 | 指向原站页面，供查阅完整结构、正文和图示；链接不代表已经翻译 |
| 代码示例 | 说明概念或改编工作流；须注明运行验证状态 |

## 准确性要求

- 保留原作者、来源、版本和历史状态；撤回或删除内容不能恢复为当前建议。
- 将建议、示例、个人观点、已验证结果和数学推导分开。
- 不把统计不显著解释成证明不存在，也不从算法名称推导未经验证的效果。
- 参数给出定义和适用前提；避免用绝对措辞掩盖条件。
- 术语在[术语表](GLOSSARY.md)统一；代码字段名按软件原样保留。
- 对同一内容只维护一个主文件，其余目录作为入口，减少版本分叉。

## 后续全文翻译

若后续取得适当授权，或由用户提供原文文件供翻译，应按固定原文版本逐段对应，保留标题、段落、删除状态、公式、脚注、图注和代码来源，并逐项更新[覆盖清单](COVERAGE.md)。未完成项保持明确标识，不用目录齐全代替全文完成。

## 图示

本轮新增的四张图是独立制作的人工教学示例，不是原文图像或真实脑电数据。真实记录的判断训练请结合原文图示与示例数据。图示的简化不能视为伪迹的完整定义。
