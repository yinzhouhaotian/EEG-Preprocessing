# 代码示例的状态与使用范围

本目录保留仓库既有改编代码，便于对照学习。它们不是经本轮验证的官方原始脚本，也不是可直接套用所有数据的标准管线。本轮修订了说明与过强承诺，没有运行 MATLAB 或相关插件，未据此认定接口全部兼容。

## 三份示例应怎样看

| 文件 | 内容 | 使用前特别检查 |
|---|---|---|
| [单被试示例](makoto_batch_pipeline.m) | 把多种处理组合在一起 | 实际通道类型、采集参考、滤波目标、有效秩、成分选择和头模配准 |
| [群组频谱示例](eeglab_official_spectral_study.m) | 多数据集和条件的示意管线 | 数据组织、函数对数据集数组的支持、条件字段与统计单位 |
| [源空间连接示例](eeglab_roiconnect_pipeline.m) | 源活动及连接指标示例 | 源模型与头模区分、配准、插件版本、采样率及等时长选项 |

硬编码的坐标转换不保证适合你的电极布局；固定的特征值容差不保证适合不同物理单位；概率阈值不保证适合不同数据人群。头模生成、坏导插值和去成分都会影响后续模型，应结合[质量检查](../Learning_Guide/09_Pipeline_and_Quality_Control.md)逐项核对。

## 小例子与整套脚本分开

学习指南中的短代码只解释一个概念，通常要求已有正确加载的数据；没有承诺独立运行。当前目录的整套示例包含多项前提，先阅读每个函数帮助，并在原始数据副本上检查一个代表性被试。

来源入口：[官方自动管线](https://eeglab.org/tutorials/11_Scripting/automated_pipeline.html)、[连接插件文档](https://eeglab.org/plugins/roiconnect/)。对照原文脚本后再根据研究目的改编，记录改动，不把改编稿标为逐字官方代码。
