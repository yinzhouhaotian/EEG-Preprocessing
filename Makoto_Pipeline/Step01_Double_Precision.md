## 旧指令为何不再作为统一步骤

早期建议要求在偏好设置中取消单精度。原文已经撤回该操作，并说明相应分解函数在需要时会自行转换精度。因此，不应要求所有版本、所有操作都全程双精度；也不能把历史删除线省略后重新写成当前规定。

## 需要学会的原理

浮点数只能保存有限有效位数。单精度常占4字节，双精度常占8字节；双精度能区分更接近的数，但占用更多内存。二者差异对矩阵秩、很小的特征值和病态矩阵尤其重要。增加精度不能消除测量噪声，也不能创造新的独立信号。

## 如何使用

自行编写矩阵运算时，先用 `class(EEG.data)` 查看类型，需要时在该运算中使用 `double(...)`。不要将改变全局偏好设置与检查输入精度混为一谈。

```matlab
% 教学检查：需要先加载数据；不修改磁盘上的原始数据
dataClass = class(EEG.data);
X = double(reshape(EEG.data, EEG.nbchan, []));
disp(dataClass);
% rank(X) 还依赖容差与缩放，不能单凭此值决定全部成分数。
```

检查：记录输入单位与类型，并结合奇异值谱、已知线性变换和数值容差评估有效秩。进一步阅读[秩与参考](../Learning_Guide/03_Reference_Interpolation_Rank.md)。
