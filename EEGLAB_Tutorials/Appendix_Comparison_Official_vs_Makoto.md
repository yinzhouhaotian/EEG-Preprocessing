# 比较两种工作流：比较前提，不评选唯一标准

官方教程与Makoto个人建议有不同目标和演进历史。不能只挑每套流程看起来最便利的步骤拼在一起，忽略参考、维度和模型一致性。

| 问题 | 应比较什么 | 不能直接推断什么 |
|---|---|---|
| 自动删除或重构 | 校准、有效信息、事件完整性与指标变化 | 保留更多点一定更真实 |
| 插值时机 | 参考集合、有效秩、分解投影和下游分析 | 插值前后任意交换都等价 |
| 高通设置 | 拟合与最终分析的目标、响应及慢波保留 | 某个数值对所有连接和功率研究都无害 |
| 参考定义 | 原始参考、通道集合、线性约束及实现 | 补零必然满秩或普通平均参考无效 |
| 成分选择 | 明确伪迹删除与高概率脑成分保留的差别 | 两种选择保留相同信息 |
| 统计与连接 | 独立单位、模型假设、数据量和选择偏差 | 指标名称能保证没有混杂 |

选择一个有明确输入假设的工作流，按[质量检查](../Learning_Guide/09_Pipeline_and_Quality_Control.md)验证，再记录有理由的改动。

来源：[官方总目录](https://eeglab.org/tutorials/)、[Makoto原文](https://eeglab.ucsd.edu/wiki/Makoto%27s_preprocessing_pipeline)。
